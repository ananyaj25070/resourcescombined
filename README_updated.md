# IIIT-Delhi Course Resources

A consolidated, community-maintained collection of course materials for students at IIIT-Delhi. This repository brings resources from three earlier student repositories into one browsable course-wise directory.

## Finding resources

Select a course from the index below. Within each course, materials are generally grouped by year and, where relevant, by section or resource type (such as lectures, quizzes, assignments, and examinations). Folder names and availability vary because the material comes from different student contributions.

For example:

- `OS/OS 2025/OS 2025 SecA/` and `OS/OS 2025/OS 2025 SecB/` contain separately organized section resources.
- `CO/CO 2024/` contains 2024 course resources.
- `PNS/PNS-B 2025/` contains Section B materials for 2025.

Some materials are repeated across years, sections, or self-contained lab projects intentionally. The availability of a resource here does not guarantee that it matches the latest course syllabus or assessment format.

## Source repositories and acknowledgements

This consolidated collection was built from **three student-maintained source repositories**. Credit for the original uploads, organization, notes, solutions, and other educational materials belongs to the contributors of those repositories.

| Source during consolidation | Credit and preserved material |
| --- | --- |
| **Repository one (`repo-one`)** | Original contributors to the first source collection. Its preserved [README](./archive/source-repositories/repo-one/README.md) provides source context. |
| **Repository two (`repo-two`)** | [NalishJain/IIITD-PYQs](https://github.com/NalishJain/IIITD-PYQs) and its contributors. The original [README](./archive/source-repositories/repo-two/README.md) is retained. |
| **Repository three (`repo-three`)** | Original contributors to the third source collection. Its [README](./archive/source-repositories/repo-three/README.md), [documentation](./archive/source-repositories/repo-three/docs/), and supporting scripts are retained. |

The original repository metadata and documentation are kept under [`archive/source-repositories/`](./archive/source-repositories/) for attribution and reference. These archived materials are not a second course-resource index.

The consolidation involved bringing course folders into a common root, organizing some year/section directories, removing verified redundant copies and generated build files, and preserving distinct resources and self-contained project dependencies. **This organizational work does not replace credit to the original contributors.**

If you contributed material and would like your attribution corrected or expanded, open an issue or pull request with the relevant source reference.

## Contributing and corrections

Contributions of missing assignments, lecture notes, quizzes, exam papers, rubrics, and solutions are welcome when you have permission to share them. Place files in the relevant course and year folder, use descriptive filenames, and avoid uploading private information, copyrighted materials without permission, or generated build output.

For missing files, incorrect course/year placement, broken links, or attribution concerns, [open an issue](https://github.com/ananyaj25070/resourcescombined/issues) or submit a pull request.
